## Method

The original 2017 LAZ is read in blocks. The 200 × 200 m study area is divided into 1,600 cells of 5 × 5 m. For each cell, terrain is the median of class 2 ground points and surface is the highest eligible return. Withheld points are excluded. The cell needs at least three applicable points to support each model. This threshold is an exploratory support rule and does not quantify positional accuracy. Source classes 19 and 20 remain unresolved and may contribute to the all-return surface. The height difference uses only cells supported by both models. It describes a cell rather than an individual tree or building.

The data support 1,212 terrain cells, all 1,600 surface cells and 1,212 height differences. The 388 terrain gaps are retained as missing values in plots and as blank cells in CSV. The unresolved vertical datum applies to source elevations. Within-survey height differences use the same source Z reference. No interpolation is applied to empty grid cells.

The images are requested from GeoSampa's WMS with matching EPSG:31983 bounds and 512 × 512 output dimensions. Year labels come from the layer identifiers. Visual differences can come from imagery acquisition and alignment as well as changes on the ground. No change areas or rates are calculated. Imagery is obtained on demand from the source service.

## Rebuild and verify

```powershell
python release.py
python audit.py
python models.py
python release.py --record
python -m unittest discover -s tests
```

The first command verifies the delivered package. The record command creates a new manifest after a deliberate rebuild. The application provides the manifest and model CSV for download.

Checked with the actual LAZ: original audit tests, grid counts, height mask, V3–V6 Streamlit pages, and PNG responses for both GeoSampa requests. Browser appearance on Windows is still to be checked locally.
