# V2 Point Cloud Explorer

Open this folder in PyCharm on Windows. In its terminal run:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Open http://localhost:8501. The preview and original historical LAZ are included.

- **Colour by → Source RGB** shows colour channels from the original file, scaled from 16 bits to 8 bits for display.
- **Custom classes** lets you choose any combination of source classes. Codes 19 and 20 remain unresolved.
- **Prepare interactive HTML export** downloads a standalone view of the selected sample, including the chosen camera preset. Use the plot camera icon for a PNG of the current browser view.
- **Display detail** limits the sample rendered by the browser. The audit counts use all points inside the study area.
- Run `python audit.py` to rebuild the bundled preview.

The V2 preview contains 100,000 sampled points with aligned RGB values. The full audit counted 665,333 points. V3 terrain and surface models remain planned.
